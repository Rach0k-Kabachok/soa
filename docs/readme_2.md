# Второе задание

## Решение

Оставил Go и `net/http` из первой части. Каталог, заказы и авторизацию собрал в одном
приложении с PostgreSQL: по заданию заказ и остатки нужно изменять в одной транзакции.

В [OpenAPI](../openapi/marketplace.yaml) описал методы, DTO, ограничения и ошибки.
Через `oapi-codegen` генерирую модели и маршруты, запросы проверяю через `kin-openapi`.
Сгенерированный код добавил в `.gitignore`, при Docker-сборке он создаётся заново.

БД создаю через Flyway. Добавил индекс по статусу товара, автоматические даты
и мягкое удаление через `ARCHIVED`. Для списка сделал пагинацию и фильтры по заданию.

Создание, обновление и отмену заказа выполняю в транзакциях. Проверки идут в порядке
из задания, товары и промокоды блокирую через `FOR UPDATE`. Цены сохраняю в позициях
заказа, деньги считаю через `decimal.Decimal`. При обновлении пересчитываю скидку,
при отмене возвращаю остатки и использование промокода.

Для переходов состояний добавил `POST /orders/{id}/status`, доступный ADMIN.
Фразу «в ином случае цена 100%» понял так: при процентной скидке свыше 70 скидка равна нулю.

Сделал JWT с access на 15 минут и refresh на 7 дней, роли и владение проверяю по матрице.
При регистрации разрешил USER и SELLER, ADMIN назначаю через `users.role` и повторный вход.
Каждый запрос логирую в JSON с полями из задания и `X-Request-Id`, пароли и токены маскирую.

## Запуск

Все команды выполняю из корня репозитория:

```sh
docker compose up --build -d --wait
curl -i http://127.0.0.1:18080/health
docker compose logs api
```

Compose запускает БД, применяет миграцию и поднимает API на порту 18080.
Интервал операций задаю через `ORDER_INTERVAL_MINUTES`, по умолчанию одна минута.
Останавливаю через `docker compose down`.

## Проверка

Для генерации кода нужен Go 1.26+:

```sh
go generate ./internal/api
```

Запросы выполняю по OpenAPI, данные проверяю вручную через SQL:

```sh
docker compose exec db psql -U marketplace -d marketplace
```

```sql
SELECT * FROM products;
SELECT * FROM orders;
SELECT * FROM order_items;
SELECT * FROM promo_codes;
SELECT * FROM user_operations;
```
